# ESP32-C3 GPIO 定义

GPIO号不是封装脚号。具体封装脚号按所采购 ESP32-C3/C3FH4 数据手册对应；本固件假定4MB Flash。

| 信号 | GPIO | 接线/备注 |
|---|---:|---|
| 继电器 OUT | 3 | HIGH 开启，LOW 关闭；接普通3.3V逻辑兼容继电器模块 IN |
| 微动开关1 | 4 | NO触点接CTRL_GND；内部上拉，按下true |
| 微动开关2 | 5 | 同上，35ms去抖 |
| BL0942 UART RX | 6 | 接光耦输出的 BL0942 TX，控制侧3.3V逻辑 |
| BL0942 UART TX | 7 | 经光耦送 BL0942 RX；4800bps、8N1 |
| CF1预留 | 10 | 接隔离后的CF1；本版不使用 |
| 配网按钮 | 0 | NO接CTRL_GND，长按3秒配网；可单独增加 |
| USB D- / D+ | 18 / 19 | 保留芯片原生USB下载/调试 |
| UART0 RX / TX | 20 / 21 | 保留3.3V串口下载/115200日志 |

GPIO2/8/9为启动相关脚，本项目不用于继电器/输入；GPIO9保留BOOT按钮接地，EN保留复位。GPIO12~17留给Flash（外置Flash芯片/内置Flash型号按官方设计）。GPIO4~7与外部JTAG复用，若使用这些IO不要再接外部JTAG；可用USB Serial/JTAG。

建议GPIO3外接10kΩ下拉，确保芯片复位和烧录期间模块输入保持关闭；启动代码拉低不能保证复位前的电平。GPIO输出只能驱动模块的逻辑输入，不能直接接裸继电器线圈。模块输入若要求5V HIGH，需做电平/驱动匹配后再画板。

开关/继电器模块共用隔离后的 CTRL_GND，不能跨接 HOT_GND。BL0942 的 HOT_GND 仍在火线域，串口/CF1只能经隔离通信进入ESP32；这份引脚文档不改变原电源隔离方案。

裸芯片还需3.3V电源去耦、EN、电源时序、40MHz晶振、天线匹配和4MB Flash或选内置Flash型号。PIO的开发板名用于构建参数，不表示必须采购开发板。
