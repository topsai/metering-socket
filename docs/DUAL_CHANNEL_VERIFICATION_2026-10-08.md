# 1.1.0 双路同步验证 · 2026-10-08

[返回首页](../README.md) · [硬件原理图](../hardware/schematics/README.md)

暂停安全任务 400ms 的测试确认硬件定时器 IRAM 中断仍会到期将 GPIO0/1 拉低。该测试验证引脚和软件行为，没有验证线圈磁场或机械触点。

安卓实板测试暴露 HTTP socket 复用导致的响应截断，已改为 `Connection: close`。原始后台轮询与并行测试入口重新验证通过，没有添加自动重试开关命令。

## 未验证与保留问题

- 开发板只接 USB，未接 BL0942、微动开关、LED、继电器或市电负载。读回 GPIO 不代表外接器件已完成电气测试。
- CF1 测试通过串口向运行计数器注入；尚未用真实光耦 CF1 波形验证边沿及频率精度。累计电量仍采用 UART CF_CNT。
- INA 为开启方向是可反转的暂定值，须使用所购继电器低压实测核对极性和动作时间。触点无反馈，突然掉电可能保留原触点状态。
- 尚未验证自焊板的 RF、时钟、上电复位、供电瞬态、光耦及隔离电源绝缘、PCB 爬电距离、真实手机与热点配网。
- 原理图主体仍有一项既有 DRC 错误及六项警告；控制页零错误、三警告。旧客户端接口未定位错误，也未完成导入往返和视觉审核。发布原理图不等于批准投板。
- 新界面截图遇到模拟器 System UI 覆盖，未发布该截图；仓库首版截图明确标为历史界面。

本机凭据、USB 注入记录、完整含 PCB 的导出和私有截图均在忽略目录中。仓库只发布筛选后的原理图副本、代码、必要测试、文档和正式构建产物。
