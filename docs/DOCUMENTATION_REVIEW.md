## 修订结果

| 审核项 | 修订 |
|---|---|
| 连接方式 | 同一局域网且可互相访问时，HTTP 直连可在没有 MQTT 服务的情况下使用；MQTT 是可选的另一条接入路径，两者可同时启用 |
| HA和远程使用 | HA 接入需运行 HA 与 broker；电脑是可选部署主机。离家使用需已配置的 HA 安全入口或 VPN，App 的 HA 按钮打开网页 |
| 继电器状态 | `relay` 是控制器逻辑输出，没有触点反馈；不能写成已测得负载通断。OTA 时 GPIO 另受强制关闭约束 |
| 密码更新 | MQTT 缺省密码保留；Wi-Fi 提交 SSID 时须显式提交密码。当前缺省/null密码会转换成字面值 `"null"`，不描述为空密码或保留旧值 |
| 配置副作用 | 有效保存撤销手动请求、取消倒计时并断开 MQTT；跟随模式可能按条件重新输出，不能保证持续关闭 |
| MQTT重连 | 十秒是尝试间隔，不是连接完成时限；以实际连接状态确认恢复 |
| 遗嘱和状态 | 异常断线触发遗嘱；正常 DISCONNECT 不触发，当前实现可能保留旧 online。区分 HA 的 unknown 和 unavailable |
| 暂停与故障 | 健康计量下解除锁定或每日 ON 可恢复暂停；真实故障需主动解除，不能写成暂停只能通过复位恢复 |
| OTA范围 | 区分认证拒绝、进入上传后的关闭/锁定以及中断回调；App 文件上限写为 1,900,000 字节 |
| Android与令牌 | Android 15 对应 API 35，最低运行配置是 Android 8.0/API 26；设备令牌是 32 个十六进制字符，承载128位随机值 |
| 命令示例 | 区分 Bash 和 PowerShell，示例使用占位令牌；PIO指定正式环境，安卓模拟器集成测试指定 `PanelTest` |
| 验证时点 | 首版“当时未测”与后续实板结果分开；没有fixture时返回的实板测试不能作为已执行证据 |
| 硬件与许可 | GPIO下拉阻值需结合模块验证，不承诺“确保关闭”；原创代码许可证状态和第三方许可证分别说明 |
